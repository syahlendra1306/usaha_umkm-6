PANDUAN SETUP DATABASE DAN ADMIN — PROMOSI UMKM

PENTING
Website statis GitHub Pages tidak bisa menyimpan kiriman bersama secara aman tanpa backend. Versi ini menggunakan Supabase (ada paket gratis) sebagai database dan login admin. Tidak ada kode akses rahasia yang ditanam di HTML/JavaScript karena pengunjung dapat melihat source code. Admin memakai email + kata sandi Supabase.

A. BUAT DATABASE SUPABASE
1. Buka https://supabase.com dan buat akun/proyek baru.
2. Beri nama proyek, buat database password yang kuat, pilih region terdekat yang tersedia.
3. Buka SQL Editor > New query. Salin seluruh isi file supabase/schema.sql, lalu Run.
4. Buka Project Settings > API. Salin Project URL dan anon/public key.
5. Buka file js/supabase-config.js. Ganti ISI_PROJECT_URL_DI_SINI dan ISI_ANON_PUBLIC_KEY_DI_SINI dengan nilai dari dashboard. Jangan pernah memakai service_role key.

B. BUAT AKUN ADMIN BARU
1. Di Supabase buka Authentication > Users > Add user / Create new user.
2. Masukkan email admin yang kamu kuasai dan buat kata sandi admin baru. Simpan dengan aman; jangan kirim ke orang lain.
3. Setelah user dibuat, salin UUID/ID user tersebut dari daftar Authentication > Users.
4. Buka SQL Editor dan jalankan perintah ini dengan UUID asli:
   insert into public.admin_users (user_id) values ('UUID-USER-ADMIN');
5. Halaman admin ada di https://USERNAME.github.io/NAMA-REPOSITORY/admin.html
6. Login dengan email dan kata sandi yang dibuat pada langkah 2.

C. UPLOAD KE GITHUB
Upload semua isi folder ini ke root repository (jangan upload ZIP). Pastikan index.html berada di root, serta folder css, js, dan supabase ikut terupload. Setelah konfigurasi Supabase diisi, commit perubahan. Aktifkan Settings > Pages > Deploy from a branch > main > /(root).

D. ALUR PENGAJUAN
Pengunjung mengisi Daftarkan Usaha. Data masuk ke tabel businesses dengan status pending. Admin membuka admin.html, login, lalu memilih Setujui atau Tolak. Hanya status approved yang tampil di halaman publik.

KEAMANAN
- Jangan taruh password admin, service_role key, atau kode rahasia di file HTML/JS.
- Anon key Supabase memang digunakan di frontend; keamanan data dijaga oleh Row Level Security dari schema.sql.
- Jangan menonaktifkan RLS. Batasi akun admin.
- Ini versi awal tanpa upload foto usaha; dapat ditambahkan kemudian memakai Supabase Storage.
